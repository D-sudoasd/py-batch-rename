# 文件批量重命名

独立的 Python 批量改名工具：添加文件、即时预览、写盘、撤回。没有会员墙，没有数量上限。

这是优速文件批量重命名（`yoso-rename`）的**独立替代实现**，不是它的源码移植，也不包含其品牌、登录、支付或广告。

## 安装与运行

需要 Python 3.10+。

```text
pip install -r requirements.txt
python run.py
```

也可以：

```text
python -m py_batch_rename
```

依赖：`PySide6`、`openpyxl`。Windows 上可以改文件的创建时间和修改时间。

## 八种命名方式

| 命名方式 | 做什么 |
| --- | --- |
| 自定义 | 新文件名 + 编号（起始 / 增量 / 位数） |
| 替换 | 查找并替换文件名中的文字 |
| 插入 | 在文件名头、文件名尾或指定位置插入文字或编号 |
| 删除 | 删除指定内容，或按开始位置 + 长度删除 |
| 时间属性 | 修改创建时间和/或修改时间（Windows） |
| 导入表格 | Excel / CSV 第一列按列表顺序作为新文件名；文件会保留原来的拓展名 |
| 一键删除 | 去掉括号、空格、字母、数字或引号 |
| 时间命名 | 用创建时间或修改时间生成文件名（四种时间样式） |

大小写转换（不变 / 全部大写 / 全部小写 / 首字母大写 / 首字母小写）适用于除「导入表格」和「时间属性」以外的方式。文件还可以设置新拓展名，或替换拓展名中的文字，并单独改拓展名大小写。

## 使用前会看见什么

- 规则一变，表格「新文件名」列立刻预览，不会先改磁盘。
- 同一批里两个文件要改成同一个名字时，会标「批次内目标重名」，拦住写盘。
- 「自然排序」让 `2` 排在 `10` 前面；自定义编号按排好的顺序重新编号。
- 「命名撤回」把上一次成功的重命名改回去（改时间属性除外）。
- 把鼠标放在工具栏按钮、命名方式、编号和拓展名变更上，会显示中文说明。
